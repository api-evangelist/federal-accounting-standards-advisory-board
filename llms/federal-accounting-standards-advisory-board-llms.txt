# Federal Accounting Standards Advisory Board (FASAB)

> FASAB is the U.S. federal advisory board that sets generally accepted accounting principles for the
> federal government and its component reporting entities. It publishes the FASAB Handbook, Statements
> of Federal Financial Accounting Standards (SFFAS), technical releases, interpretations and staff
> implementation guidance, and runs the board and ASIC meeting process behind them.
>
> FASAB publishes NO developer program, NO API documentation and NO machine-readable specification.
> Its website runs on WordPress and serves the standard WordPress REST API anonymously at
> https://fasab.gov/wp-json/ — a real, callable, read-only content API over 402 pages, 4 posts,
> 214 media records and site search. The OpenAPI below was DERIVED by API Evangelist from that live
> route discovery document on 2026-09-09; every operation in it was confirmed HTTP 200 anonymously.
> FASAB did not author, publish or endorse it.
>
> IMPORTANT LIMIT: the authoritative pronouncements are PDFs on files.fasab.gov, linked from page
> content. This API will tell you which page carries a standard and where its PDF lives. It will not
> give you the text of a standard as structured data.

## APIs

- [FASAB Public Content API (WordPress REST)](https://fasab.gov/wp-json/): Anonymous read-only access
  to FASAB pages, posts, media, taxonomies, authors and site search. 28 verified operations. No key required.

## What does not exist

- No developer portal, API reference, getting-started guide or support channel for the API.
- No SDKs or client libraries in any registry; no CLI; no Postman collection.
- No GitHub organisation (api.github.com/orgs/fasab returned 404 on 2026-09-09).
- No MCP server, no A2A agent card, no /llms.txt, no /.well-known/ documents of any kind.
- No webhooks, no events, no AsyncAPI, no GraphQL, no gRPC and no SOAP surface.
- No status page, no changelog, no sandbox, no OAuth scopes, no trust centre and no published certifications.
